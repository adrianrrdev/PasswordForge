# 🔐 Password Forge

Password Forge es un generador de contraseñas
seguras creado como parte de ProyectoZ.

## Funciones

- Generación de contraseñas
- Longitud configurable
- Mayúsculas
- Minúsculas
- Números
- Símbolos
- Mostrar y ocultar contraseña
- Copiar al portapapeles
- Diseño responsive

## Tecnologías

- HTML
- CSS
- JavaScript

## ProyectoZ

Este generador forma parte de ProyectoZ,
un proyecto personal para aprender desarrollo
web, IA y creación de productos digitales.
